# F07 / F08 final hardening — 2026-10-09

Scope: Warehouse Transfer pagination and browser CI only. No staging access, deployment, reset/seed, new migration, F06 or F09 work. Existing F01–F05 business commands are unchanged.

## F07

Root cause: `listTransfers` silently stopped at 100 rows, `incomingTransfers` was unbounded, and the inventory/create-transfer UI checked for active transfers using that truncated list.

Correction:

- Both read endpoints now use bounded server pagination, shared search predicates, snapshot-consistent totals and an ID tie-breaker. Transfers support direction, status, transfer/tracking-code search and exact shipment; the incoming queue retains its fixed destination + IN_TRANSIT scope and oldest-dispatch ordering.
- Defaults: page 1 / limit 20, maximum limit 100. Responses expose `items`, `page`, `limit`, `total`, `totalPages`; `incomingTransfers` contains that page object. Invalid query values return 400.
- Warehouse workspace reuses SearchFilter, SelectField and Pagination for both directions. Search/status/warehouse changes reset the page; tab counts use the server total. Receiving uses the existing command and confirmation.
- Inventory receives a bounded active-transfer projection per shipment. Opening the transfer form rechecks that shipment's pending/in-transit records rather than searching an arbitrary list page.

Rules preserved: backend warehouse ownership/RBAC, authorized read scope, valid lifecycle transitions, append-only tracking/audit and retry idempotency. No generic status mutation or frontend authorization substitute.

Regression evidence: 115 PostgreSQL fixture transfers, including 105 equal-timestamp IN_TRANSIT transfers, 3 other statuses and 7 outside the warehouse scope. Seven HTTP/E2E cases cover both directions/all, every page, totals, filters, input bounds, inventory active transfer, auth/RBAC/ownership and successful receipt/retry of record 101 with exactly one tracking/audit event. Browser checks cover both page-6 lists, search/status reset, record-101 receipt, inventory controls, loading/error/retry/empty states and no overflow at 375/768/1440 px.
