# Vietnam administrative snapshot

- Source: [Open Admin Data / Vietnam](https://github.com/open-admin-data/vietnam-administrative-divisions/tree/54cdb052284b02e75dfaa44089ca383aa12c57db).
- Pinned revision: `54cdb052284b02e75dfaa44089ca383aa12c57db`; source updated 2026-09-08; vendored 2026-09-18.
- Upstream dataset license: **CC BY 4.0**, copyright 2026 jakkrapongt; original notice in `LICENSE.txt`. UI includes credit and license links. Changes: stripped bilingual/metadata fields, renamed keys, converted coordinate strings to numbers; no names/codes/coordinates invented.
- Administrative basis: [Decision 19/2025/QĐ-TTg](https://vanban.chinhphu.vn/?classid=1&docid=214409&pageid=27160), issued 2025-06-30, effective 2025-07-01. 34 provinces/cities directly parent 3,321 wards/communes/special zones; no district hierarchy.
- Every province/ward code, Vietnamese name and ward parent was compared by the vendor script with the upstream Decision 19 dataset [ThangLeQuoc v3.0.2, commit 78594ea](https://github.com/ThangLeQuoc/vietnamese-provinces-database/tree/78594ea643d5fdebd640ea3889ea91f84b9463ae). `SOURCE.json` records SHA-256 of inputs and output. This is a pinned Decision 19 snapshot, not a promise of automatic incorporation of subsequent legislation.
- Coordinate provenance: upstream [methodology](https://github.com/open-admin-data/vietnam-administrative-divisions/blob/54cdb052284b02e75dfaa44089ca383aa12c57db/docs/methodology.md) cites `tranngocminhhieu/vietnamadminunits` for province points and OpenStreetMap/Nominatim batch geocoding for ward points. Geographic data attribution: **© OpenStreetMap contributors**, [ODbL](https://www.openstreetmap.org/copyright). Upstream's CC BY notice does not remove underlying OSM database rights; the adapted geographic database is distributed here in editable JSON with its sources and transformation script.
- These are approximate navigation hints, not official boundaries, surveyed addresses, service eligibility, or confirmed delivery coordinates. Range/finite checks do not establish geographic accuracy. A user must pin and confirm the actual location.
- Shared by the backend geocoder and frontend selectors from this single location. `code`, `name`, `provinceCode` (wards), `latitude`, `longitude` and ward `fullName` are shipped. `fullName` comes from the same pinned Decision 19 cross-check source so UI can label Phường/Xã/Đặc khu without guessing. Existing names, codes, parents and coordinates are unchanged. Codes remain strings to preserve leading zeroes. No runtime external data API or Nominatim autocomplete.

To reproduce, run `python frontend/scripts/vendor-vietnam-admin.py` from the repository root (network required only for this maintenance command). It checks counts, unique codes, parent relationships, coordinate bounds and the full administrative cross-check before writing. Review a new official snapshot and licenses before changing pinned revisions; do not blindly track `main`.
